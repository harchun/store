# Store WordPress Theme

以「一篇文章 = 一間店」為核心的 WordPress 店鋪介紹主題。

設計方向參考 fakertw.com 的店家資料呈現方式，但主題本身不依賴 WooCommerce。

## 核心概念

每一篇 WordPress 文章就是一間店鋪，文章除了正文外，可以在後台填寫：

- 地址
- 營業時間
- 電話
- LINE / 聯絡方式
- 店家性質
- 消費／坐檯模式
- 主要消費
- 包廂／場地
- 店家特色
- 消費注意事項

並可使用「城市」與「店家類型」分類。

## 首頁

- 最新店家

## 開發方向

下一階段可加入：

1. 消費計算器
2. 店家比較功能
3. 城市／區域篩選
4. 預算篩選
5. 店家推薦標籤
6. 店家評價／編輯評分資料模型
7. 店家 Google Map
8. SEO Schema / Breadcrumb

10. 店家資料批量匯入
